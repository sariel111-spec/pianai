# 偏爱档案 · The Affection Archive

一个为多梦家庭设计的、简约纸感的恋爱记录网站。原生 HTML / CSS / JavaScript，无需构建、无外部依赖，适配手机与桌面、GitHub Pages 项目子路径。

## 部署到自己的 GitHub 仓库

1. 解压后，把 `index.html`、`style.css`、`app.js`、`.nojekyll` 放在仓库根目录，不要再嵌套一层文件夹。
2. 在仓库 **Settings → Pages → Build and deployment** 中选择 **Deploy from a branch**，分支选择你上传文件的分支（通常为 `main`），目录选择 `/ (root)`，保存。
3. 等待 Pages 部署完成，打开页面显示的网站链接。仓库 Pages 可用性取决于你的 GitHub 账号和仓库设置。

也附带了 `.github/workflows/pages.yml`：如果喜欢 Actions 部署，将上述 Source 改成 **GitHub Actions**，再在 Actions 中手动运行 **Deploy Pages**。两种方法任选一种即可。

本地查看：直接打开 `index.html`。长期使用建议在固定的 Pages 地址访问；本地 file 协议的存储行为取决于浏览器。页面所有资源都在包内，无需下载字体或图片。

## 功能

- 多关系：新建、切换、编辑、删除关系，独立主题色与记录。
- 关系档案：梦女、梦角、作品、关系状态、相遇日、寄语、双方设定、相遇故事、相处默契和边界。
- 恋爱日记：正文、日期、心情、标签、关联世界。
- 心动时间线：按日期回顾关键事件。
- 纪念日：每年重复或单次日期、自动计算距离天数。
- 相册与约稿：上传本地图片（每张最多 2 MB）或使用图片 URL，记录作者、来源与授权说明。
- 往来信笺：长文书信、日期、标签、关联世界。
- 平行世界：IF 线设定、身份与关系故事。
- 心愿清单：完成 / 撤回，筛选未完成与已完成。
- 搜索：当前关系、当前分类中搜索标题、正文、标签与世界，支持日期排序。
- 备份：全量 JSON 导出 / 校验后导入，包括上传图片。
- 全部分类支持新增、编辑、删除；首次仅包含明确标记的示例，可自由删除。

## 数据与隐私

数据保存于当前浏览器的 localStorage（键：`affection-archive-v1`）。没有后端、登录、云端同步或真正的密码加密。不同浏览器、设备、域名或协议的数据彼此独立，清除浏览器数据会删除记录。定期在「备份与设置」中导出 JSON。导入会替换当前全部档案，不能合并。

localStorage 的配额由浏览器决定；大量图片会用满空间，保存失败时页面会提示并保留先前数据。推荐压缩图片，或使用自己控制的图片托管地址。远程图片服务可能收到访问请求，不要使用未经授权的图像。

**不要把私人备份 JSON 提交到公开仓库。** 本站源码和初始示例可以公开；你在浏览器里写的新记录不会自动进入仓库。此版本也不是供访客共同写入、跨设备实时同步的多人网站。

## 定制

- 网站名：修改 `index.html` 中的标题与品牌文字。
- 主题与布局：修改 `style.css`；每段关系可直接在「关系档案」里设置主题色。
- 初始示例：修改 `app.js` 的 `seed`（只影响没有本地数据的首次访问）。
- 所有用户文本按纯文本呈现，不执行用户 HTML。外链仅接受 HTTP/HTTPS；上传仅接受 PNG/JPEG/WebP/GIF。

## 检查

`node --check app.js` 进行 JavaScript 语法检查。`node checks.cjs` 运行日期、备份结构与外链过滤检查，无需安装依赖。
